# Known Issues and Limitations

Last reviewed: 2026-11-23. Items below reflect the inspected initial repository and the current open foundation PR.

1. **No browser verification.** Application behavior has only Node source and engine tests; no real browser/iPad Safari pass is recorded.
2. **Narrow mathematics support.** Numeric arithmetic and a limited linear equation grammar only; no symbolic algebra or independent substitution verifier.
3. **Learning is a demonstration.** One fixed arithmetic question; no lessons, mistake classification, progression, or mastery evidence.
4. **Persistence is minimal.** Local storage counter/preferences only; no IndexedDB, versioned schema, export, or restore.
5. **Knowledge is a stub.** A few definitions with no structured links, provenance, or verification.
6. **No model lifecycle.** No model architecture, generator, training code, evaluation, or checkpoints. Training must stay disabled absent explicit authorization.
7. **Subspace undefined.** No implementation or repository references were found.
8. **Deployment unverified.** No prior workflows/runs and Pages settings are unknown. Public URL is not verified.
9. **Research incomplete.** Only official GitHub Pages documentation was consulted for the current deployment decision; ML and math architecture research has not yet been conducted.
